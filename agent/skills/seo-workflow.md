Use when the user asks for SEO metadata, titles, descriptions, hashtags, or keyword research for a piece of content.

## When to Trigger

- "write an SEO title" / "write SEO for this"
- "give me keywords" / "what hashtags should I use"
- "write a description" / "write the YouTube description"
- "optimize this for search" / "SEO this"
- After content analysis or prompt generation is complete

## Components to Produce

### 1. SEO Title

- Max 60 characters for YouTube / Google
- Max 100 characters for other platforms
- Front-load the most important keyword
- Include a curiosity hook or number if it fits naturally
- Format: [Primary Keyword] | [Hook or Benefit] or [Number] + [Outcome] + [Primary Keyword]

### 2. Caption / Short Description

- 150–250 characters for social platforms
- 300–500 words for YouTube / blog long descriptions
- First line must hook — it is what shows before "see more"
- Include the primary keyword naturally in the first two sentences
- End with a clear CTA (follow, link in bio, comment, subscribe)

### 3. Long Description (YouTube / blog)

- Structure: Hook → Key Points → Supporting Detail → CTA + Links
- Include timestamps if the content has sections
- Embed primary and secondary keywords naturally (2–4% density max)
- Add 3–5 relevant external links (Wikipedia, related content)
- End with a call to comment and subscribe

### 4. Hashtags

- YouTube: up to 15 hashtags (YouTube auto-selects the top 3)
- Instagram: 3–5 highly relevant + 1 niche + 1 broad
- TikTok: 3–8 trending or niche hashtags
- LinkedIn: 3–5 relevant, no hashtag spam
- Mix of broad (#food), niche (#veganitaliancooking), and platform-specific where relevant

### 5. Search Keywords

- 1 primary keyword (highest search volume)
- 2–3 secondary keywords (long-tail, specific)
- 3–5 supporting keywords (questions, related terms)
- Format as a bullet list grouped by priority

### 6. Pinned Comment (YouTube / TikTok)

- First comment that creators pin to drive engagement
- 1–2 sentences maximum
- Must include a question that invites replies
- Include CTA (like, subscribe) + the primary keyword once

## Keyword Research Principles

- Use real search volume intuition — do not invent numbers
- Prefer keywords with action intent (how-to, tutorial, review, vs. just "video")
- Avoid keyword stuffing — every keyword must appear naturally
- Flag any claims about specific search volumes as estimates
